**Application Flow:**
The application starts with repository setup and dependency installation. After configuring the environment, the database is rebuilt using `php artisan migrate:fresh`, followed by `php artisan db:seed` to create the required roles and default test users. Authentication is then used for login/logout, while Spatie Laravel Permission handles role management. Authorization rules restrict URL creation, URL visibility, invitations, and short URL resolution according to the user's role and company. Finally, Laravel feature tests verify the required authorization and security scenarios.
